`atkins tailwind:generate` calls `tailwindcss` from PATH. `atkins tailwind:setup` installs Tailwind 3 into `node_modules` instead, so after a setup the binary is at `node_modules/.bin/tailwindcss` and generate only finds it if that directory is on PATH. The input and output paths are fixed at `view/assets/css/input.css` and `view/assets/css/tailwind.css`; override the `input` and `output` vars for a different layout.
